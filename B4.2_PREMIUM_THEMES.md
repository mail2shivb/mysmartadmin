## Theme Switching Behavior

### System Theme Selected
- Follows OS appearance setting
- Light appearance → Calm Neutral Light
- Dark appearance → Calm Neutral Dark
- OS changes → app switches automatically

### Explicit Theme Selected (Emerald/Indigo)
- Always uses that theme regardless of OS
- User has explicit control
- Consistent appearance across day/night

### Live Theme Switching
- Tap theme option → immediate visual change
- No save button needed
- All screens update instantly
- Colors adapt throughout app
