==============================
PRODUCT VISION (UNCHANGED)
==============================

The application is a mobile-first, offline-first, privacy-first personal
home & life management system.

It is NOT a comparison site.
It is NOT a budgeting app.

It helps users STORE, TRACK, MANAGE, and UNDERSTAND their real-world
financial, property, vehicle, and life commitments over time.

Comparison sites help users BUY.
This app helps users LIVE with what they bought.

==============================
GLOBAL NON-NEGOTIABLE PRINCIPLES
==============================

- Offline-first by default
- All user data stored locally
- No mandatory backend
- No background data uploads
- Explicit user-controlled export only
- Explicit user-controlled deletion
- GDPR-friendly by design
- Local encryption for sensitive data
- Production-grade MVP (not a prototype)

==============================
GLOBAL FUNCTIONAL REQUIREMENTS (APPLY TO ALL DOMAINS)
==============================

Every domain item MUST support:
- Manual creation
- Document-based creation (scan/upload)
- View (summary + detail)
- Edit
- Delete / archive
- Link to one or more documents
- Link to reminders/tasks
- Appear in search
- Appear in reports

Documents are a SHARED PRIMITIVE across all domains.
