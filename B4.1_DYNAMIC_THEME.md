## Theme Architecture

### Color Flow
```
User selects theme in Settings
  ↓
ThemeController.setLightTheme() / setDarkTheme() / setSystemTheme()
  ↓
notifyListeners() → triggers rebuild
  ↓
AppThemeProvider provides new AppThemeData
  ↓
Widgets read colors via AppThemeProvider.colorsOf(context)
  ↓
UI updates with new theme
```

### Semantic Color Roles (30+ properties)

**Surfaces:**
- `background` - Main app background
- `surface` - Card/container background
- `surfaceContainer` - Elevated surface

**Brand:**
- `primary`, `primaryContainer`, `onPrimary`
- `secondary`

**Semantic States:**
- `success`, `successLight`
- `warning`, `warningLight`
- `danger`, `dangerLight`
- `info`, `infoLight`

**Text:**
- `textPrimary`, `textSecondary`

**UI Elements:**
- `border`, `divider`
- `onSurface`, `onSurfaceVariant`, `onBackground`, `outline`

**Domain Icons:**
- `iconBackgroundBlue`, `iconBackgroundGreen`, `iconBackgroundOrange`
- `iconBackgroundPurple`, `iconBackgroundRed`, `iconBackgroundGrey`

## Future Theme Addition

Adding a new theme (e.g., "Warm Theme") is simple:

1. Create `lib/core/ui/themes/warm_theme.dart`:
```dart
class WarmColorScheme implements AppColorScheme {
  // Implement all 30+ properties
  @override
  Color get background => Color(0xFFFFF8F0); // Warm off-white
  @override
  Color get primary => Color(0xFFFF6F00); // Warm orange
  // ... etc
}
```

2. Add factory to `AppThemeData`:
```dart
factory AppThemeData.warm() {
  const colors = WarmColorScheme();
  return AppThemeData(
    colors: colors,
    materialTheme: _buildMaterialTheme(colors, Brightness.light),
  );
}
```

3. Add option in Settings UI
4. Done! No widget changes needed

## System Brightness Integration

The app now responds to OS theme changes:

**Implementation:**
1. `_LedgerAppState implements WidgetsBindingObserver`
2. `didChangePlatformBrightness()` detects OS changes
3. `ThemeController.updateSystemBrightness()` updates state
4. If ThemeMode.system, app switches automatically

**Testing:**
- Change OS to dark mode → app switches (if System selected)
- Change OS to light mode → app switches (if System selected)
- App ignores OS if Light or Dark explicitly selected
