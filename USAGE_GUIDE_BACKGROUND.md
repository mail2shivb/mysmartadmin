# 🎨 Custom Background Color - User Guide

## How to Change Background Color

### Step 1: Open Settings
Tap the **Settings** icon (⚙️) in the app bar on:
- Home screen
- Documents screen  
- Tasks screen

### Step 2: Navigate to Appearance
The Settings screen opens to the **Appearance** section automatically.

### Step 3: Choose Background Style
Select one of:
- **🌅 Solid** - Single color background
- **🌈 Soft Gradient** - Smooth gradient effect

### Step 4: Pick Your Color
Scroll to the **Background Color** palette:

#### Color Options Available:
1. **White** - Clean, minimal
2. **Light Grey** - Default, calm (recommended)
3. **Light Blue** - Sky-inspired
4. **Sky Blue** - Fresh, airy
5. **Medium Blue** - Ocean vibes
6. **Bright Blue** - Energetic
7. **Light Green** - Nature-inspired
8. **Soft Green** - Gentle, earthy
9. **Light Orange** - Warm, inviting
10. **Peach** - Soft, cozy
11. **Light Purple** - Creative, unique
12. **Lavender** - Calm, elegant
13. **Light Pink** - Gentle, friendly
14. **Soft Pink** - Warm, welcoming

#### How to Select:
- **Tap** any color swatch
- Selected color shows:
  - Thicker border (3px vs 1px)
  - ✓ Check icon
  - Color name displayed above
- Changes apply **immediately** throughout the app

### Step 5: Reset (Optional)
To return to the theme's default background:
- Tap the **Reset** button
- Message changes to "Using theme default"

## Pro Tips

### Best Combinations:
- **Calm Light theme** → Light Grey or White
- **Calm Dark theme** → Keep default (darker colors work best)
- **Emerald theme** → Light Green or Soft Green
- **Indigo Pro theme** → Light Blue or Sky Blue

### For Readability:
- Use **lighter colors** for better text contrast
- **Solid style** works best for focus work
- **Gradient style** adds visual interest

### Color Psychology:
- **Blues** → Calm, trustworthy, professional
- **Greens** → Natural, balanced, restful
- **Oranges/Peach** → Warm, friendly, energetic
- **Purples** → Creative, unique, sophisticated
- **Pinks** → Gentle, approachable, optimistic

## Technical Notes
- Color selection is **in-memory only** (resets on app restart)
- Works with **all themes** (Light, Dark, Emerald, Indigo)
- Gradient automatically adapts to your chosen color
- All colors are **accessibility-tested** for contrast
