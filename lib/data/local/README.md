# Database Layer (lib/data/local)

## Overview

Production-ready SQLite database implementation using Drift (Flutter's type-safe SQLite wrapper) for offline-first data storage.

---

## Quick Start

### Initialize Database

```dart
import 'package:mysmartadmin/data/local/app_database.dart';

// Create database instance
final database = AppDatabase();

// Access DAOs
final docs = database.documentsDao;
final bills = database.billsDao;
final reminders = database.remindersDao;
final subscriptions = database.subscriptionsDao;
final policies = database.policiesDao;
final links = database.documentLinksDao;
```

### Basic Operations

```dart
// CREATE
final id = await docs.insertDocument(
  DocumentsCompanion.insert(
    title: 'My Document',
    category: 'finance',
    documentType: 'receipt',
  ),
);

// READ
final doc = await docs.getDocumentById(id);

// UPDATE
await docs.updateDocumentFields(
  id,
  DocumentsCompanion(title: Value('Updated Title')),
);

// DELETE (soft)
await docs.softDeleteDocument(id);

// RESTORE
await docs.restoreDocument(id);
```

## Key Features

### ✅ Offline-First
- 100% local storage
- No network dependencies
- Works without internet

### ✅ Type-Safe
- Compile-time query validation
- Auto-generated type-safe classes
- Null-safety compliant

### ✅ Soft Delete
- Recoverable deletion
- Audit trail preservation
- `deleted_at` timestamp pattern

### ✅ Versioning
- Track changes over time
- Link to previous versions
- Full audit history

### ✅ Reactive Streams
- Real-time UI updates
- Efficient change detection
- `watch*()` methods for StreamBuilder

### ✅ Monetary Values
- INTEGER storage (cents/pence)
- No floating-point errors
- Example: £10.50 → 1050

### ✅ JSON Storage
- Flexible metadata
- OCR extracted data
- Complex nested structures

## Common Patterns

### 1. Creating with Relationships

```dart
// Create document
final docId = await docs.insertDocument(...);

// Create reminder for document
await reminders.createReminder(
  RemindersCompanion.insert(
    documentId: Value(docId),
    title: 'Review document',
    reminderType: 'review',
    reminderDate: DateTime.now().add(Duration(days: 30)),
  ),
);

// Link to another document
await links.createLink(
  DocumentLinksCompanion.insert(
    sourceDocumentId: docId,
    targetDocumentId: otherDocId,
    linkType: 'related',
  ),
);
```

### 2. Querying with Filters

```dart
// Get expiring documents
final expiring = await docs.getDocumentsExpiringBetween(
  DateTime.now(),
  DateTime.now().add(Duration(days: 30)),
);

// Get overdue reminders
final overdue = await reminders.getOverdueReminders();

// Get active subscriptions
final active = await subscriptions.getActiveSubscriptions();
```

### 3. Calculating Costs

```dart
final billsCost = await bills.calculateMonthlyTotal();
final subsCost = await subscriptions.calculateMonthlyTotal();
final policyCost = await policies.calculateMonthlyTotal();

final totalCents = billsCost + subsCost + policyCost;
final totalPounds = totalCents / 100;

print('Total monthly: £$totalPounds');
```

### 4. Reactive UI with Streams

```dart
StreamBuilder<List<ReminderEntity>>(
  stream: database.remindersDao.watchPendingReminders(),
  builder: (context, snapshot) {
    if (!snapshot.hasData) return LoadingWidget();
    
    final reminders = snapshot.data!;
    return ListView.builder(
      itemCount: reminders.length,
      itemBuilder: (context, index) {
        final reminder = reminders[index];
        return ReminderCard(reminder: reminder);
      },
    );
  },
);
```

### 5. Version Management

```dart
// Create new version
final newVersionId = await bills.createBillVersion(
  existingBillId,
  BillsCompanion(
    amountCents: Value(12000), // Price changed
    updatedAt: Value(DateTime.now()),
  ),
);

// Get version history
final versions = await bills.getBillVersions(existingBillId);
print('Has ${versions.length} versions');

// Access previous versions
for (final version in versions) {
  print('Version ${version.version}: £${version.amountCents / 100}');
}
```

### Future Migrations

Add to `app_database.dart`:

```dart
@override
MigrationStrategy get migration {
  return MigrationStrategy(
    onCreate: (m) async => await m.createAll(),
    onUpgrade: (m, from, to) async {
      if (from < 2) {
        // Example: Add new column
        await m.addColumn(documents, documents.newColumn);
      }
      if (from < 3) {
        // Example: Create index
        await m.createIndex(
          Index('idx_expiry', 'SELECT * FROM documents WHERE expiry_date IS NOT NULL')
        );
      }
    },
  );
}
```

## Performance Tips

### 1. Use Batch Operations
```dart
await database.batch((batch) {
  for (final doc in documents) {
    batch.insert(documentsDao.documents, doc);
  }
});
```

### 2. Use Streams for UI
```dart
// ✅ Good - reactive updates
stream: database.documentsDao.watchAllDocuments()

// ❌ Bad - manual polling
Timer.periodic(Duration(seconds: 1), (_) async {
  final docs = await database.documentsDao.getAllDocuments();
  setState(() => _docs = docs);
});
```

### 3. Selective Column Reads
```dart
// When you only need specific columns
final query = selectOnly(documents)
  ..addColumns([documents.id, documents.title]);
```

### 4. Add Indexes (Future)
```dart
// In migration
await m.createIndex(Index('idx_expiry', 'documents', 'expiry_date'));
```

## Troubleshooting

### Issue: "Table doesn't exist"
**Solution:** Run code generator:
```bash
dart run build_runner build --delete-conflicting-outputs
```

### Issue: "Foreign key constraint failed"
**Solution:** Ensure referenced records exist or use nullable FKs.

### Issue: "Database is locked"
**Solution:** Don't perform long-running operations in transactions.

### Issue: Generated files out of sync
**Solution:** Delete generated files and regenerate:
```bash
find . -name "*.g.dart" -delete
dart run build_runner build
```

## Best Practices

### ✅ DO
- Use soft delete for important data
- Create versions for audit trails
- Use streams for reactive UI
- Store money as integers (cents)
- Batch insert multiple records
- Close database when done

### ❌ DON'T
- Store large files in database (use filesystem)
- Use floating-point for money
- Poll the database (use streams)
- Hard delete important data
- Forget to handle null cases
- Leave database connections open
